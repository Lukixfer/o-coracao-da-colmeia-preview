# 💖 Apoie “O Coração da Colmeia”

Se esta obra está te acompanhando, você pode apoiar a continuidade e a revisão com uma contribuição via Pix.

## Pix

- Chave Pix (e-mail): `KlausKhaus@hotmail.com`
- Como contribuir:
  1. Abra o app do seu banco e escolha Pix.
  2. Selecione a opção “Chave Pix”.
  3. Informe a chave de e-mail: `KlausKhaus@hotmail.com`.
  4. Defina o valor e, se quiser, escreva uma mensagem (ex.: “Apoio Colmeia”).
  5. Confirme o envio.

Sugestões simbólicas: R$ 5, R$ 10, R$ 20. Qualquer valor ajuda.

## Transparência

- Doações não compram decisões criativas nem prioridade de mudanças; servem para manter tempo de revisão, edição e publicação.
- Não há contrapartida obrigatória, reembolso ou benefícios pagos. O conteúdo da preview permanece público.
- Se quiser ser mencionado nos agradecimentos, abra uma Issue dizendo “Apoiei via Pix” (sem dados sensíveis) e o nome como gostaria de aparecer.

Obrigado por ajudar a manter este coração pulsando. 💛
